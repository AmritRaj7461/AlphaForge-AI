# Finance Tool Specification

## Purpose

Retrieve financial metrics used for investment analysis.

---

## Metrics

- Revenue
- Net Income
- EPS
- PE Ratio
- ROE
- ROA
- Market Cap
- Debt
- Cash Flow
- Revenue Growth

---

## Output

Standardized Financial JSON.

---

## Responsibilities

- Fetch metrics.
- Normalize values.
- Handle missing data.
- Return structured JSON.

---

## Rules

Never calculate recommendations.

Never invoke Gemini.
