# Dashboard Specification

## Purpose

The Dashboard is the primary workspace where users interact with the generated investment report.

---

## Sections

- Search Bar
- Company Overview
- Financial Summary
- News Timeline
- Risk Analysis
- Competitor Comparison
- SWOT Analysis
- Recommendation Card
- Confidence Meter
- Explainability Panel
- Follow-up Chat

---

## UX Principles

- Responsive
- Minimal
- Professional
- Interactive
- Data-first

---

## States

Loading

↓

Success

↓

Partial Report

↓

Error

---

## Acceptance Criteria

- Displays structured report.
- Updates dynamically.
- Supports dark mode.
- Responsive across devices.
