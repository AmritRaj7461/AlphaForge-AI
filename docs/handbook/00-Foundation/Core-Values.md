# Core Values

## 1. Transparency

Every recommendation must be explainable.

---

## 2. Reliability

The platform must continue operating even when external services fail.

Graceful degradation is mandatory.

---

## 3. Evidence First

Opinions without supporting evidence should never influence recommendations.

---

## 4. Human Control

Artificial Intelligence supports decision making.

Final decisions always belong to the user.

---

## 5. Continuous Evolution

The architecture must remain flexible enough to support future autonomous AI agents.

---

## 6. Engineering Excellence

Maintainable software is more valuable than complicated software.

Simplicity enables scalability.
