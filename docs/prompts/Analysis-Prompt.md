# Analysis Prompt

## Purpose

Construct the primary analysis prompt sent to Gemini.

---

# Input

Company Information

Financial Data

Market News

Risk Assessment

Competitor Analysis

---

# Prompt Template

Analyze the following company using the supplied structured information.

Tasks

1. Summarize the company.

2. Analyze financial performance.

3. Analyze growth potential.

4. Analyze market risks.

5. Compare against competitors.

6. Produce SWOT Analysis.

7. Recommend

BUY

HOLD

SELL

8. Explain every recommendation.

9. Mention assumptions.

10. Mention limitations.

---

# Required JSON Output

Company Overview

Financial Summary

Risk Summary

Competitor Summary

SWOT

Recommendation

Reasoning

Confidence Explanation

Limitations
